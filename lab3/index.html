Lab 3: Web Data Acquisition

This dataset contains earthquake records collected from the United States Geological Survey earthquake catalog. The records shown here are the first 1,000 earthquakes from 2024 in chronological order.

Source: USGS Earthquake Catalog API

Method: REST API using Python and requests.

Records collected: 1,000

Attributes

  • id: unique event identifier assigned by USGS.
  • time_utc: time when the earthquake occurred, in UTC.
  • place: short text description of the event location.
  • magnitude: measured earthquake magnitude.
  • depth_km: estimated earthquake depth in kilometers.
  • longitude: east-west geographic coordinate.
  • latitude: north-south geographic coordinate.
  • tsunami: whether a tsunami flag was assigned, where 1 means yes and 0 means no.
  • felt_reports: number of public reports submitted to USGS, when available.
  • significance: USGS significance score based on factors such as magnitude, felt reports, and impact.
