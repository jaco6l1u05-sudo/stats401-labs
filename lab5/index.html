Lab 5: Interactive Network Visualization with D3

This visualization represents a synthetic urban transit network containing 50 stations and 50 direct transit connections. Stations belong to five districts and have different passenger volumes and station types. Routes have a travel time and a transit service type.

Node-Link Design

The node-link diagram uses color to represent district, node size to represent daily passenger volume, and shape to represent station type. Larger nodes indicate higher passenger volume, while circles, squares, and triangles represent Local, Transfer, and Terminal stations. Link width represents travel time, so longer connections appear thicker, while link color represents route type. Dragging allows the network structure to be explored, and hovering highlights connected stations and displays station information in a tooltip.

Adjacency Matrix Design

The adjacency matrix uses stations as both rows and columns. Colored cells represent direct connections. Cell color represents route type, while cell opacity represents travel time. Station labels are colored by district. This makes individual connections easy to locate and provides another way to inspect the network structure without relying on the spatial layout of the node-link diagram.

Network Questions and Findings

  1. Which stations appear central in the network?
    Answerability: Well. View: Node-link. The node-link diagram makes local connectivity easiest to see. Stations such as Stations 4, 7, 10, 13, 16, 18, 21, 23, 25, 29, 31, 33, 34, and 38 appear more central because they have more direct connections.
  2. Which districts are strongly connected to one another?
    Answerability: Partially. View: Both. District colors help identify the endpoints, while the matrix makes connection patterns easier to compare. East–South has the strongest cross-district connection pattern, although the matrix is not ordered by district.
  3. Where are transfer or terminal stations located in the topology?
    Answerability: Well. View: Node-link. Shapes make these stations easy to identify. Transfer stations are shown as squares and terminal stations as triangles, and they are distributed throughout the network rather than being confined to one region.
  4. Which stations have high passenger volume?
    Answerability: Well. View: Node-link. Passenger volume is encoded by node size, so the largest stations are immediately visible. Station 50 has the highest passenger volume and appears as one of the largest nodes.
  5. Where are the longest direct travel-time connections?
    Answerability: Well. View: Both. Thicker links identify longer travel times, while matrix cell opacity provides another indication. The longest direct connection is between Station 7 and Station 31 at 16 minutes.
  6. Are particular route types concentrated in particular parts of the network?
    Answerability: Partially. View: Both. Route colors can be followed in the node-link diagram and compared in the matrix. Express, Shuttle, and Metro routes are distributed across the network, with no strong concentration in one particular region.
