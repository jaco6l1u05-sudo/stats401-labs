Lab 6: Hierarchical Data Visualization - Trees and Treemaps

This visualization represents a hierarchical global GDP dataset containing countries from different continents and areas. Countries have different GDP values and GDP status categories indicating whether their GDP has increased, remained unchanged, or decreased.

Treemap 1: Squarify

Treemap 2: Binary

GDP Status

■ Increase ■ Unchanged ■ Decrease

Design description

Both treemaps use rectangle area to represent GDP, so countries with larger GDP values occupy larger areas. GDP status is represented by color: green indicates an increase, gray indicates unchanged GDP, and red indicates a decrease. The hierarchy is organized from World to continent, area, and country, allowing users to examine GDP at different levels of the hierarchy. Tooltips provide additional information about each country. The two treemaps use different spatial subdivision strategies. The first uses Squarify, which generally tries to keep rectangle aspect ratios closer to squares. However, countries with very large GDP values can still produce large or elongated rectangles. The second uses Binary tiling, which recursively divides the available space into two groups. This produces a different spatial arrangement and can make the divisions of the hierarchy more apparent. Comparing the two layouts demonstrates how tiling strategy can change the spatial organization of the same data while preserving the same GDP and status encodings.
