Lab 8: Web Text Data and Visualization

This visualization explores the Duke Kunshan University Undergraduate Instruction Bulletin 2021–2022 using semantic embeddings, semantic topics, and the original bulletin structure.

Corpus Summary

The cleaned corpus contains 2,682 meaningful text passages. The average passage contains approximately 37.4 words, while the median passage length is 11 words. The corpus contains 127 formal bulletin sections.

The largest formal sections by passage count are Course Descriptions and Majors, showing that the corpus contains substantial detailed academic and course information.

Semantic Analysis

Semantic embeddings were generated using the all-MiniLM-L6-v2 Sentence Transformer model. The resulting 384-dimensional embeddings were reduced to two dimensions using UMAP with 15 neighbors, a minimum distance of 0.15, cosine distance, and random state 401.

K-Means clustering with 8 clusters was used to organize passages into semantic topics. The clusters were interpreted using representative passages and TF-IDF terms.

Semantic Embedding Map

Each point represents one bulletin passage. Position represents semantic similarity in the 2D UMAP projection. Color represents semantic topic, and point size represents passage length.

Analytical Questions

1. What are the major semantic topics?

The clustering identifies eight broad topics: Arts, Media & Humanities; Academic Policies & Study Away; Chinese Studies & History; Social Sciences & Culture; Course Prerequisites; Environmental & Health Sciences; Political Science & Public Policy; and Computer Science & Natural Sciences.

2. Do semantic topics appear across multiple formal sections?

Yes. The Topic × Section matrix shows that several semantic topics occur across multiple formal bulletin sections. This demonstrates that semantic organization does not always follow the Bulletin's formal hierarchy.

3. Can passages from different sections be semantically similar?

Yes. Selecting a passage displays its five most semantically similar passages. These neighbors can come from different formal sections, revealing relationships that are not obvious from the original document structure.

4. Does a keyword search correspond to only one semantic topic?

Not necessarily. A search term can occur in passages belonging to multiple semantic topics. Combining search with topic and section filters allows these different semantic contexts to be explored.

Design Description and Findings

This visualization uses two coordinated views to compare the formal structure of the Duke Kunshan University Undergraduate Instruction Bulletin with its semantic structure. Each passage is represented as one point in the embedding map. UMAP reduces the 384-dimensional sentence embeddings to two dimensions so that semantically similar passages can be viewed near one another. Position therefore represents semantic similarity, rather than two independently interpretable variables. Color represents the semantic topic assigned by K-Means clustering, while point size represents passage length. These encodings provide multiple attributes without overcrowding the map. The Topic × Bulletin Section matrix provides a complementary view of the same corpus. Rows represent the Bulletin's formal sections, columns represent semantic topics, and cell intensity represents the number of passages in each combination. Search, section filtering, and topic filtering allow users to focus on specific parts of the corpus, while zooming and panning support exploration of dense regions. Clicking a passage displays its metadata, original text, and five nearest semantic neighbors. Clicking a matrix cell highlights the corresponding passages on the semantic map, creating a coordinated interaction between the two views. The visualization shows that semantic topics can cross formal section boundaries, providing a different way to explore relationships within the Bulletin.
